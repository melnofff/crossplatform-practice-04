Вариант 4 — мини-чат с публичным эхо-сервером WebSocket.

## Запуск

Node.js 24.x и npm 11+. Выполните `npm ci`, затем `npm start`.
Откройте http://localhost:3000/index.html в Chrome или Edge.
Открытие файла через file:// не позволяет зарегистрировать Service Worker.

Текст заметки сохраняется только в localStorage этого браузера и origin.
Очистка данных сайта удаляет заметку. Чат требует сети; эхо-сервер
возвращает отправленный текст и не является перепиской с другим человеком.

## Состав проекта

- `pwa-note/index.html` — интерфейс и сохранение заметки.
- `pwa-note/manifest.json`, `icon.png`, `icon-512.png` — описание приложения и иконки.
- `pwa-note/service-worker.js` — предварительное кэширование, очистка предыдущих версий и cache-first.
- `pwa-note/function.wat`, `function.wasm` — исходный и бинарный модуль квадрата числа.
- `pwa-note/app.js` — загрузка Wasm, проверка ввода и эхо-чат WebSocket.
- `pwa-note/serve.json` — отключение перенаправления адресов HTML-файлов.

## Проверка работы

1. После запуска дождитесь загрузки модуля и регистрации Service Worker. Перезагрузите страницу.
2. Введите заметку, обновите страницу и проверьте сохранённый текст.
3. Нажмите «Вычислить квадрат»: для 7 ожидается 49. Допустимы целые числа от −46340 до 46340, чтобы результат помещался в знаковый i32.
4. Подключитесь к эхо-серверу и отправьте тестовое сообщение. В истории должны появиться отправленная строка и такой же ответ.
5. В DevTools → Application проверьте манифест, активный Service Worker и кэш `pwa-note-v4` с шестью ресурсами.
6. Включите Network → Offline, перезагрузите страницу и повторите вычисление. Заметка должна сохраниться; чат требует подключения к сети.
7. Верните сетевой режим. Для чата нажмите «Подключиться» повторно.

Альтернативный локальный адрес — http://127.0.0.1:3000/index.html.
Он имеет отдельный origin: данные заметки и кэш не общие с localhost.

## Обновление и установка

При изменении оболочки измените `CACHE_NAME` в `service-worker.js`.
Обработчик activate удаляет только прежние кэши с префиксом `pwa-note-`.
`skipWaiting` и `clients.claim` ускоряют переход на новую версию.

Для проверки установки используйте предусмотренную Chrome или Edge команду установки приложения.
Затем запустите «PWA Заметка» из списка приложений Windows и проверьте отдельное окно.
Обычное открытие сайта во вкладке само по себе не подтверждает установку.
